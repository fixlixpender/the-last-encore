# The Last Encore

A dark, sound-powered 2.5D platformer built with Three.js and modern JavaScript.

The city has been swallowed by **The Silence**. A weathered guitarist crosses rain-soaked districts with his guitar on his back, collecting lost notes and restoring sound one live show at a time.

## First playable slice

- A bearded guitarist with his guitar travelling on his back
- Side-scrolling movement, jumping and platform collisions
- A dark, rainy city rendered entirely with Three.js geometry
- Five collectible musical notes with reactive sound
- A rooftop stage and end-of-level guitar solo
- Keyboard controls and responsive presentation

## Controls

| Action | Keys |
| --- | --- |
| Move | `A` / `D` or arrow keys |
| Jump | `W`, `Space`, or up arrow |

## Run locally

No dependency installation is required. Start a local server with:

```bash
npm run dev
```

Then open `http://localhost:5173`. Three.js is loaded as an ES module from jsDelivr.

## Direction

This initial prototype establishes the atmosphere and core platforming loop. Next milestones include character animation, a shadow enemy, sound-powered switches, checkpoints, an original soundtrack and a fully designed first level.
